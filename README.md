# Mama sagt… — Kaffee

Готовая HTML/CSS-страница меню, повторяющая переданный макет. Без платных библиотек, регистрации посетителей и JavaScript.

## Просмотр

Откройте `index.html` в браузере. На телефоне страница автоматически подстраивается под ширину экрана.

## Публикация через GitHub Pages

1. Создайте новый **Public** репозиторий на GitHub (например, `mama-sagt-menu`).
2. Загрузите `index.html` и `style.css` **в корень репозитория** (не нужно загружать всю папку как вложенную).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch** → `main` → `/(root)` → **Save**.
5. GitHub покажет адрес вида `https://USERNAME.github.io/mama-sagt-menu/`. Ссылка и будет адресом вашего QR-меню.
6. После изменений в файлах опубликованная страница обновится, а ссылка останется прежней.

Обратите внимание: GitHub Pages публикует страницы в открытом доступе. Этот вариант подходит для меню без персональных данных и не содержит панели редактирования блюд.

## Правки

- **Название и цена**: в `index.html` каждая строка — отдельный `<li class="menu-item">`.
- **Фон**: в `style.css` свойство `--lavender: #D0A9FF`.
- **Шрифт и интервалы**: настраиваются в `style.css`.

Цены и названия намеренно перенесены из предоставленного изображения без добавления новых товаров. Шрифт Arial/Arial Black — доступная системная замена, поскольку исходный шрифт Figma не был предоставлен. Для точного совпадения можно позже подключить используемый вами веб-шрифт.
